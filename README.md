# Java Date Entry Organizer

A Java application that reads date entries with optional letter codes, groups dates by matching letter combinations, and organizes entries without letters into a separate category.

## Features

- Reads user-entered date records
- Supports optional letter codes
- Case-insensitive grouping
- Preserves original input formatting
- Outputs results to a file and the console

## Technologies Used

- Java
- File I/O
- Collections
- String Processing

## Example Input

5/1/2023 B
8/13/2024 mb
8/20/2024
